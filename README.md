# Farmer John's Systems Lab

This repository contains the static website and interactive HTML simulations for Farmer John's Systems Lab.

## Publishing with GitHub Pages

1. Place the contents of this folder at the root of a public GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. When GitHub provides the site address, open the landing page and test each simulation.

Each simulation has a stable relative address under `/simulations/`. The landing page's **Copy Canvas link** buttons produce full addresses after the site is published.
